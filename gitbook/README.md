# Welcome to Conduit

**Conduit Pay** is a USDC payment infrastructure built on Arc Network, powered by Circle.

Send and receive USDC instantly — no bank account, no KYC, no complicated setup.

---

## What you can do with Conduit

| Feature | Description |
|---------|-------------|
| Payment Links | Create a shareable link, get paid in USDC in under a second |
| Escrow | Lock USDC safely until delivery is confirmed |
| Username Payments | Get paid at `conduitpay.xyz/u/yourname` |
| Stealth Mode | Optional privacy — hide your real wallet address |
| Multi-Chain | Accept payments from Ethereum, Base, Arbitrum, and more |
| x402 Facilitator | Gate any API behind USDC micropayments — AI agents pay automatically |
| AI Dispute Agent | Gemini-powered mediation for escrow disputes |
| Email Notifications | Get notified for every payment event |
