## Completed

- Payment links with stealth mode
- Multi-chain support via Circle CCTP V2
- 0.5% fee system, admin + analytics dashboards
- Seedless wallets via Privy
- Username payments and @username pages
- Contacts
- x402 facilitator — first on Arc
- `@ace_won/x402` npm package (v1.0.2)
- Developer docs
- Circle Developer-Controlled Wallets for escrow
- Escrow with delivery windows and auto-resolution
- AI Dispute Agent — Gemini 2.0 Flash
- x402 API Marketplace
- Email notifications via Resend
- Custom domain — conduitpay.xyz
- Rate limiting and security hardening

## In Progress / Next

- Arc mainnet launch (waiting on Arc Network)
- Reputation system — trust scores per wallet
- Webhook support for escrow status changes
- `@ace_won/x402` v2 — Express/Node.js support
