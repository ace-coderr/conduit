Conduit is built for four types of users.

## Freelancers & Creators

Get paid in USDC without sharing your wallet address. Create a payment link, share it anywhere, and receive funds in under a second.

- No wallet address exposed
- No network selection required
- Works from any chain the payer is on
- 0.5% fee — no other charges

## Businesses

Collect payments with escrow protection. Funds are held securely in a Circle Developer-Controlled Wallet until delivery is confirmed. Fully automated — no middleman, no arbitrator.

- Escrow with Circle MPC custody
- Auto-release after delivery confirmation
- AI-powered dispute resolution
- Email notifications for every event

## Developers

Monetize any API with one line of code. AI agents pay automatically per request in USDC. List your API on the Conduit Marketplace and earn passively.

```bash
npm install @ace_won/x402
```

```typescript
export const GET = withPayment({ amount: "0.001" }, handler);
```

Your API now earns USDC per request.

## Anyone, Anywhere

No bank account needed. No KYC. Works in any country. Sign up with just an email address, Google account, or passkey.

- Seedless wallets via Privy
- No MetaMask required
- No seed phrase
- Available globally
